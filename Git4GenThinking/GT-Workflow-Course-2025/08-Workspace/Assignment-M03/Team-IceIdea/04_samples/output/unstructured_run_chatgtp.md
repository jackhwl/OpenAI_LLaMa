## 三、遇到的问题与原因分析

结合实验结果，当前主要存在以下问题：

### 1. 性能指标为 0 的异常现象

**可能原因分析：**

1. **数据标注问题**
   - 标注格式错误（如类别索引不一致、空标注）
   - 标注文件与图像未正确对应
   - 类别数与配置文件不一致
2. **数据集划分问题**
   - 验证集中可能不存在有效目标
   - 训练集与验证集类别分布严重不均衡
3. **模型输出与评估逻辑不匹配**
   - 类别数（num_classes）配置错误
   - 标签名称或类别 ID 偏移（如从 1 开始而非 0）
4. **阈值或评估参数设置问题**
   - 置信度阈值过高，导致未输出任何有效预测框
