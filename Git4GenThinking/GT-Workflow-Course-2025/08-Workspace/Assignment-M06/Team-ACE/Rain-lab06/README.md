# Lab06 — 本地智能体运行环境实验
## 1. 实验目标
本实验旨在构建一个最小可行智能体（MVA），
使其能够在本地知识环境中，借助远程 LLM 完成
“检索 → 决策 → 行动 → 反思”的持续工作流。
---
## 2. 运行环境说明
- 本地知识库：Obsidian
- 推理与规划：Cherry Studio
- 远程模型：
  - [ ] Qwen
  - [x] DeepSeek
  - [ ] 其他（请注明）
---
## 3. 本地知识结构设计
我的 Obsidian 知识库采用分层结构设计：

**核心目录结构**：
- `notes/` - 原始知识笔记（包含3条基础笔记）
- `concepts/` - 抽象概念节点（包含RAG、COT、KG等10+概念）
- `projects/` - 长期任务/目标（包含"构建智能笔记助手"项目）
- `actions/` - 行动计划（包含每周知识整理计划）
- `reflection/` - 反思记录

**连接机制**：
- 使用双向链接建立笔记间关联
- 概念采用原子化设计原则
- 项目与具体行动、反思形成闭环
---
## 4. Agentic Workflow 说明
我的智能体工作流遵循"Evaluate → Act → Reflect"循环：

### 触发条件（Trigger）
- **定期触发**：每周固定时间执行知识库整理
- **条件触发**：当概念连接度低于阈值时启动优化
- **手动触发**：需要特定知识整理时人工启动

### 决策方式（Evaluate）
1. **远程LLM规划**：通过Cherry Studio调用DeepSeek模型
2. **结构化输出**：要求模型生成JSON格式的行动计划
3. **人工确认**：对复杂决策进行人在回路确认

### 行动类型（Act）
1. **人工执行**：按照行动计划手动执行整理任务
2. **状态标记**：实时更新行动计划完成状态
3. **数据记录**：记录执行时间和关键发现

### 反思机制（Reflect）
1. **问题识别**：分析执行过程中的瓶颈和冗余
2. **改进建议**：基于反思提出工作流优化方向
3. **知识沉淀**：将反思记录写入知识库供下次参考
