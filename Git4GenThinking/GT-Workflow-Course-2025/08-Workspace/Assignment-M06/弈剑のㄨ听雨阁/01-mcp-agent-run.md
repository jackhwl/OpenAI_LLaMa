1. **核心定义**   
    _引用来源:_ [知乎的一篇文章](https://www.zhihu.com/tardis/zm/art/675509396) 提到生成式思维是“通过新技术、新方法，生产新的知识或创意”，这与传统思维的“基于已有知识的分析和归纳”形成对比。
- [x] 人工筛选并整理为学习要点
生成式思维（Generative Thinking）是一种创造性和系统性的思维方式，强调通过创新的思路来生产新的想法、概念或解决方案。它与传统思维（如分析性思维）有明显的区别：

1. **核心定义**  
    生成式思维被广泛认为是创造性思维的一种表现形式，关注如何从现有信息中“生成”新的内容。这种思维强调开放性、想象、探索和创新，而不是单纯地分析已有数据。  
2. **与传统思维的区别**
    
    - **目标不同**：  
        生成式思维的目的是创造新内容，而传统思维强调从现有信息中提取逻辑、判断或结论。
    - **思维方式不同**：  
        生成式思维更注重“发散性思维”和“联想”，寻找潜在的可能；传统思维则注重“收敛性思维”和“验证”，强调逻辑和确定性。
    - **应用场景不同**：  
        生成式思维适用于创意开发、问题解决等需要创新的场景；传统思维适用于数据分析、决策支持等需要严谨推理的场景。
生成式思维的核心在于激发认知资源，通过引入新视角和构思新可能性，从而构建新的知识体系或解决方案。

## Reflect

- MCP 是否必要？
否。生成式思维和传统思维的定义以及它们的区别，可以通过已有的知识和逻辑推理明确表达出来，没有必要调用外部资料。例如，生成式思维的基本概念可以从心理学和认知科学的理论中推导，如发散性思维、创造性问题解决等。

- 哪些信息其实可以只靠本地知识？
大部分基础概念、核心定义以及生成式思维与传统思维的主要区别都可以通过本地知识解答。例如：
- 生成式思维的定义（创造性的、开放性的思维模式）；
- 传统思维的特点（分析性、逻辑性、验证性）；
- 两者在目标、思维方式和应用场景上的差异；
- 如何通过发散性思维产生新想法等。

- 下次是否可以减少 MCP 调用？
是的，如果问题可以根据现有知识解答，可以尽量减少MCP调用以提高效率。但如果有需要深入了解具体理论、研究或实际案例，则仍然需要调用MCP来辅助。所以，在提出问题时，应清楚区分哪些需要外部资料支持，哪些可以通过现有知识回答。
