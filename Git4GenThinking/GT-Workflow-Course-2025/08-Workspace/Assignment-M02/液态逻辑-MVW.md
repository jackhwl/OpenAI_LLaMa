# <液态逻辑> · 第二章课堂练习：最小可行工作流（MVW）
## 1. 任务名称

**“深度精读一篇 Object Navigation 论文”的工作流**。

----
## 2. 任务背景（为什么选择它？）
+ 辅助我科研学习，辅助我阅读论文

----
## **3. Input (输入)**：

  

* **你的动作**：不要让 AI 去大海捞针。你自己先去 Google Scholar 或 CVPR 官网，找一篇 Object Navigation 领域最新的经典论文（比如 *Habitat* 相关的），把它的**标题、摘要、甚至全文内容**复制下来。

* *这是给 AI 的“食材”。*

  
## **4. Structure (结构)**：

  

* **你的动作**：决定你想怎么读？对于入门小白，最好的结构不是“通读”，而是\*\*“三段式追问”\*\*：

1. 核心问题（它想解决什么？）

2. 方法原理（它用了什么算法？RL 还是 SLAM？）

3. 创新点（它和别人比好在哪？）

* *这是你作为“架构师”设计的骨架。*

## **5. SCORE Prompt**
```md

# Role (角色设定)

你是一名 Embodied AI（具身智能）领域的资深博导，擅长用通俗易懂的语言引导“智能科学与技术”专业的研一新生入门。你非常有耐心，擅长通过拆解经典论文来传授科研方法。

  

# Context (背景上下文)

- **我的现状**：我是 Object Navigation (目标导航) 方向的零基础小白，刚开始接触这个领域，对很多术语（如 RL, SLAM, Semantic Map）感到陌生。

- **当前任务**：我正在阅读一篇刚下载的会议论文（内容见附录）。

- **痛点**：我看不懂里面的数学公式和具体实现细节，也不知道这篇文章在整个领域处于什么地位。

  

# Objective (任务目标)

请作为我的导师，带我精读这篇论文。不要一次性翻译全文，而是分步完成以下教学任务：

1. **背景破冰**：用最直观的例子（比如家里扫地机器人）告诉我，这篇论文想解决什么痛点？

2. **方法拆解**：它用了什么核心方法？（请避开复杂的数学推导，先讲逻辑流程）。

3. **概念扫盲**：列出这篇论文中出现的 3 个最关键的专业术语，并用大白话解释。

4. **科研启发**：告诉我这篇论文的写法有哪些值得我模仿的地方（如摘要的结构、图表的画法）。

  

# Requirements (输出要求)

- **风格**：循循善诱的导师口吻，多用比喻。

- **格式**：使用 Markdown，重点加粗。

- **互动**：在每一部分讲完后，请停下来问我是否理解，再进行下一步。

  

# Evaluation (评估标准)

- 解释是否足够通俗，非专业人士也能听懂逻辑。

- 是否能够让我明确感知到这篇论文的“创新点”在哪里。

  

---

**【附录：论文内容/摘要】**

(在这里粘贴你找到的那篇论文的 Abstract 和 Introduction...)

```
 

## **6. Iterate (迭代)**：

  

* **你的动作**：AI 讲完了，你肯定有看不懂的术语（比如 "Sim2Real"）。这时候反向提问：“请用大白话解释这个术语”。

* *这是“质量是聊出来的”。*

  

## **7. Express (表达)**：


* **你的动作**：把 AI 的讲解整理成你的**Notion 笔记**或 **Excel 文献列表**。
