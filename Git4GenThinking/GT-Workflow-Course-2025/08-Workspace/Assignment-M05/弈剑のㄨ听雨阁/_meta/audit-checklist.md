# 🛡 知识库质量审计表

每次进行“知识库维护”时，请按顺序执行：

## 1. 结构完整性检查
- [ ] **孤立节点**：检查 Graph View 中是否有未连接的白点。
- [ ] **元数据规范**：随机打开 3 个概念卡片，检查 YAML 是否在第一行。
- [ ] **图片归档**：确认所有图片都在 `/_attachments` 文件夹（需配合设置）。

## 2. 链接健康度
- [ ] **死链检查**：是否有指向不存在文件的链接？（显示为暗色）
- [ ] **反向链接**：重要概念是否有至少 2 个反向链接？

## 3. 内容质量
- [ ] **语义分块**：长笔记是否都用了 H2 标题分割？
- [ ] **来源标注**：所有引用内容是否都加了来源链接？
