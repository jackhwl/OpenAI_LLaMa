| 工具名称                 | 类型判定 | 理由分析                            | 改造思路 (如何闭环?)                                 |
| -------------------- | ---- | ------------------------------- | -------------------------------------------- |
| **ChatGPT (网页版)**    | 开环系统 | 只有我提问它才回答，回答完就静止了，不会自动把回答存入文档。  | 结合 API + Python 脚本，让它每天早上自动把“昨天的对话总结”发到我的邮箱。 |
| **Obsidian Copilot** | 半闭环  | 它能根据指令修改当前笔记，但需要我手动点击“插入”或“接受”。 | 允许它在后台自动给所有新笔记打标签，无需询问。                      |
| **Midjourney**       | 开环系统 | 生成图片后，我不保存链接就丢了。                | 接入 Discord Bot，生成后自动下载并按 Prompt 分类存入本地文件夹。   |
