# 最小知识库配置
## 方案选择
- **第四章方案**：直接读取本地文件夹（零配置，适合小规模资料）
- **第七章方案**：完整 RAG 知识库（向量化+语义检索，适合大规模资料）
## 本地文件夹方案
### 目录结构
```text
docs/sources/
├── paper1.md          ← 论文 1
├── paper2.md          ← 论文 2
├── blog-post.md       ← 博客文章
└── official-doc.md    ← 官方文档
```
### 使用方法
1. 把研究资料放入 `docs/sources/` 文件夹
2. 资料格式支持：Markdown (.md)、纯文本 (.txt)、PDF (.pdf)
3. 在工作流步骤 3（资料检索）中，读取这些文件作为补充来源
### 检索方式
- **按文件名匹配**：如果知道资料名称，直接读取
- **按关键词搜索**：在文件内容中搜索关键词，返回匹配的文件
- **手动指定**：在研究问题中指明"参考 docs/sources/paper1.md"
### 局限性
- 不支持语义搜索：只能匹配关键词，不能理解"意思相近"
- 资料规模有限：超过 20 篇文档时效率下降
- 需要手动维护：新增资料需要手动放入文件夹
## 扩展到完整 RAG（第七章）
当资料规模超过 20 篇，或需要语义搜索时，升级到完整 RAG 知识库：
1. 资料接入：自动监控文件夹变化
2. 文档切块：按段落或语义切块
3. 向量化：用 Embedding 模型生成向量
4. 检索：语义搜索返回最相关的内容块
详见第七章"知识库打包"。
