# 第二课提示词档案 · 赤壁·风起

这个目录里的 `.txt` 就是**实际发给模型的提示词**。课程把它们从 `server.py` 里抽出来，
是为了让"模型到底被下了什么命令"变成一件能直接打开看的事——
没有人能在不给你看提示词的前提下，让你相信它生成的那段话。

## 三条约定

1. **以 `##` 开头的行是注释**，只给人看，不会发给模型。怎么写都不会影响生成结果。
2. **改这些文件不用重启服务**。`server.py` 每次收到请求都重读一遍，改完刷新页面就生效。
   你可以试着把叙述者的语气改一遍，再点同一个决策，观察叙事怎么变。
3. **`{占位符}` 由服务端用真实数据填**（比如 `{scene_title}` `{delta}`）。别删。

## 文件清单

| 文件 | 发给谁 | 决定什么 |
|---|---|---|
| `base_rules.txt` | 叙事 + 结局断语 | **硬性约束**：可用词汇、不许虚构什么 |
| `narrator_system.txt` | 叙事模型 | 每一幕的文风 |
| `ending_system.txt` | 结局断语模型 | 收尾的语气 |
| `council_system.txt` | 参谋团五位 | 谋士的人格设定 |
| `consequence_user.txt` | 叙事模型 | 这一幕的具体任务 |
| `ending_user.txt` | 结局断语模型 | 收束全文的任务 |
| `council_user.txt` | 参谋团五位 | 局势 + 三个选项 + 一句「说出你的主张」 |
| `image_style.txt` | 生图模型 | 统一画风的后缀（追加在插画提示词尾部） |
| `stat_labels.json` | 服务端拼 `{delta}` | 四个态势维度的显示名与补注 |

## 换题材必改清单

示例是赤壁，**但你完全不会被迫再写一遍赤壁**。换题材时按这张表改：

| 改什么 | 在哪 | 不改会怎样 |
|---|---|---|
| **可提及的人物名单** | `base_rules.txt` 第 3 条 | 模型写你的家乡战役时，张口还是曹操孙权 ← 最容易忘的一条 |
| 时代词汇范围 | `base_rules.txt` 第 1 条 | 出现不该有的现代术语，或用错时代的说法 |
| 叙述者语气 | `narrator_system.txt` | 「《三国演义》风格」换不掉，文风串味 |
| 谋士身份 | `council_system.txt` | 幕僚还说着「汉末孙权帐中」 |
| 态势维度名 | `stat_labels.json` | 「军心 / 水战 / 天时 / 曹疑」放在你的题材里可能根本说不通 |
| 事件名 | `ending_user.txt` | 结尾那句「如何改写了赤壁」永远是赤壁 |
| 画风 | `image_style.txt` | 你写的是近代题材，配图还是水墨绢本 |

**这张表只覆盖"发给模型的文字"。** 剧本、判定规则、选项插画、谋士称谓、
验收脚本里也硬编着题材，完整清单见本课 `README.md` 的「换题材」一节。
**提示词、剧本、素材三样都改，才叫换了题材。**

## 弄坏了怎么恢复

```
git checkout -- lab/prompts/          # 在 lesson-02-chibi-game/ 目录下执行（仓库根没有 lab/）
```

注意：`python tools/gen_prompts.py`（在**仓库根**的 `tools/` 下，不在 `lab/tools/`）
**默认不会覆盖**你已经改过的文件，
只有加 `--force` 才会。

> `server.py` 现在**没有**任何提示词副本：删掉这里的文件，它会在你下一次点击时
> 直接报错告诉你缺哪个文件，而不是悄悄用一份旧的顶上。这是故意的——
> 早先那份看不见的兜底副本，正是"改了半天没效果"的根源。

## 为什么要公开这些

这门课的一条主线是：**AI 生成的内容不能直接当知识**。

要做到这一点，至少得能回答"它凭什么这么说"。看一下 `council_system.txt` 就会明白，
谋士之所以说话那样，不是因为它真的懂历史，而是因为system 里写了"总长 80 字以内、不要现代词汇"。
**把因果摆在明面上，你才有资格判断它哪句话不能信。**
