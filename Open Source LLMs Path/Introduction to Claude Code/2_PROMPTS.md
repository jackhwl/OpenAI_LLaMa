# Prompts used in the course

## Concert ticket marketplace site

### Initial prompt to create the prototype

> Generate a prototype of a website for selling concert tickets.  Include a page that lists all available concert tickets.  Information for each event should include the artist name, venue name, event date, and ticket price.  Make up fake artist and venue names as placeholders, and use a placeholder image service instead of real images.  Any event can be clicked to show a details page.  That details page should have an add to cart button, and when that's pressed, the page should store that ticket in a shopping cart.  Use a simple SQLite database for local storage, and cookies to store the current contents of the cart.  I want this prototype to use HTML, CSS, and JavaScript, but no frameworks like React or Angular.

### Prompt to trigger the Read tool

> Pick one function in the server file and explain it to me.

### Prompt to trigger the WebSearch tool

> Can you explain the difference between versions 9 and 10 of the better-sqlite3 library?
